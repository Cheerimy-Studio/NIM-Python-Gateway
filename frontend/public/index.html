快速开始

curl 示例
curl https://your-gateway-domain.example/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-****" \
  -d '{
    "model": "zhipu/glm-4-flash",
    "messages": [{"role": "user", "content": "你好，介绍一下自己"}],
    "stream": true
  }'
Python（OpenAI SDK）
from openai import OpenAI

client = OpenAI(
    base_url="https://your-gateway-domain.example/v1",
    api_key="sk-****",   # 任意密钥均可；公告见 QQ 频道（pd57362562）
)
resp = client.chat.completions.create(
    model="zhipu/glm-4-flash",
    messages=[{"role": "user", "content": "你好"}],
    stream=True,
)
for chunk in resp:
    print(chunk.choices[0].delta.content or "", end="")
JavaScript
const res = await fetch("https://your-gateway-domain.example/v1/chat/completions", {
  method: "POST",
  headers: { "Content-Type": "application/json",
             "Authorization": "Bearer sk-****" },
  body: JSON.stringify({
    model: "zhipu/glm-4-flash",
    messages: [{ role: "user", content: "你好" }],
    stream: true,
  }),
});
for await (const chunk of res.body) {
  console.log(new TextDecoder().decode(chunk));
}

API 文档

AQUA 网关完整兼容 OpenAI 协议，所有端点均可直接用 OpenAI SDK 调用。统一入口见「首页」，以下为各端点的详细说明、调用示例与错误码。API Key 加 QQ 频道（频道号 pd57362562）获取，模型列表请以「模型列表」页为准（实时同步）。

GET/v1/models

获取可用模型列表。返回 Nvidia NIM、Gitee AI、SiliconFlow、智谱 GLM、讯飞星火、官方自营与 Workers AI 的全部模型。

响应结构

{"object": "list",
  "data": [{
    "id": "zhipu/glm-4-flash",
    "object": "model",
    "owned_by": "zhipu"
  }]}

curl

curl https://your-gateway-domain.example/v1/models
  -H "Authorization: Bearer sk-****"

POST/v1/chat/completions

对话补全，支持流式（SSE）。根据填入的模型 ID 自动路由到对应上游。

请求体

{"model": "zhipu/glm-4-flash",
  "messages": [
    {"role": "system", "content": "你是 AQUA 助手"},
    {"role": "user", "content": "你好"}
  ],
  "temperature": 0.7,
  "stream": true  // 可选，流式返回
}

python

from openai import OpenAI
client = OpenAI(api_key="sk-****", base_url="https://your-gateway-domain.example/v1")
r = client.chat.completions.create(
  model="zhipu/glm-4-flash",
  messages=[{"role": "user", "content": "你好"}])
print(r.choices[0].message.content)

POST/v1/embeddings

向量化。向量模型（如 BAAI/bge-m3）由 Gitee AI / SiliconFlow 提供。

curl https://your-gateway-domain.example/v1/embeddings \
  -H "Content-Type: application/json" \
  -d '{"model": "BAAI/bge-m3", "input": "AQUA 网关"}'

POST/v1/rerank

重排。用于 RAG 检索结果排序，支持 bge-reranker-v2-m3 等重排模型。

curl https://your-gateway-domain.example/v1/rerank \
  -H "Content-Type: application/json" \
  -d '{"model": "bge-reranker-v2-m3", "query": "你好", "documents": ["A", "B"]}'

POST/v1/audio/transcriptions

语音识别（ASR）。使用 multipart/form-data 上传音频文件，内容类型透传；支持 GLM-ASR、SenseVoiceSmall 等。

curl https://your-gateway-domain.example/v1/audio/transcriptions \
  -F "file=@audio.wav" \
  -F "model=GLM-ASR"

POST/v1/audio/speech

语音合成（TTS）。部分 TTS 模型的文本合成能力取决于上游平台；可携带 prompt_audio / prompt_audio_url 参考音频（语音克隆类模型）。

curl https://your-gateway-domain.example/v1/audio/speech \
  -H "Content-Type: application/json" \
  -d '{"model": "Spark-TTS-0.5B", "input": "你好，欢迎使用 AQUA"}'

POST/v1/moderations

内容安全检测。支持 Qwen3Guard-Gen-0.6B、nonescape-v0、nsfw-classifier 等风控模型。

curl https://your-gateway-domain.example/v1/moderations \
  -H "Content-Type: application/json" \
  -d '{"model": "Qwen3Guard-Gen-0.6B", "input": "待检测文本"}'

POST/v1/images/generations

文生图。由智谱 CogView 系列免费提供，模型 ID 以 zhipu/cogview- 开头（如 zhipu/cogview-3-flash）。

curl https://your-gateway-domain.example/v1/images/generations \
  -H "Content-Type: application/json" \
  -d '{"model": "zhipu/cogview-3-flash", "prompt": "一只坐在沙发上的橘猫", "size": "1024x1024"}'

POST/v1/videos/generations

文生视频。由智谱 CogVideoX 免费提供（如 zhipu/cogvideox-flash）。视频生成耗时较长，客户端超时建议设置 5 分钟以上。

curl https://your-gateway-domain.example/v1/videos/generations \
  -H "Content-Type: application/json" \
  -d '{"model": "zhipu/cogvideox-flash", "prompt": "一只小狗在草地上奔跑"}'

POST/v1/ip_location

IP 归属地查询。模型 ID 为 ip-location，由 Gitee AI 提供。

curl https://your-gateway-domain.example/v1/ip_location \
  -H "Content-Type: application/json" \
  -d '{"model": "ip-location", "ip": "8.8.8.8"}'

GET/assets/{key}

R2 媒体缓存访问。生成类接口（图片/音频/视频）产出的文件会写入缓存，可通过该路径直接访问，路径形如 /assets/{key}。

curl https://your-gateway-domain.example/assets/2026/08/abc123.png \
  -H "Authorization: Bearer sk-****"

特殊模型说明

  • Auto 路由：填入 auto 或 acu/auto，网关自动从 Nvidia 候选池随机命中一个主流模型。
  • Workers AI：模型 ID 为 workers-ai/{alias}（如 workers-ai/llama-3.1-8b），每日有免费额度，超出自动返回 429。
  • 智谱 GLM：模型 ID 为 zhipu/{model}（如 zhipu/glm-4-flash），含 CogView 绘图 / CogVideo 视频，同样免费。
  • 讯飞星火：模型 ID 为 spark/{model}（如 spark/spark-lite），由科大讯飞免费提供。
  • 官方自营：模型 ID 为 acu/{model}（如 acu/deepseek-v4-flash），由 AQUA 官方自营旗舰通道提供，长期服务、稳定可靠。
  • 自营排队：上游并发有限（全局 10 并发），高峰期会自动排队等待（先到先得，最长约 15 秒）；排队超时会返回 429 提示，请稍后重试，不要重复提交。
  • 非标准端点：embedding / rerank / asr / tts 等特殊模型已适配为标准 OpenAI SDK 端点，可直接用官方 SDK 调用。
  • 任意密钥可用：本站为开放模式，任意非空密钥均可调用（如 sk-****，中英文均可）。大版本更新与公告在 QQ 频道（频道号 pd57362562）通知。

错误与状态码

所有错误响应均采用 OpenAI 兼容的错误结构（HTTP 状态码 + JSON 错误体），客户端可直接按 OpenAI 官方错误格式解析：

{"error": {
  "message": "上游限流，请稍后重试",
  "type": "api_error",
  "code": 429
}}

HTTP 状态码

状态码含义常见原因与处理
200成功正常返回；流式请求返回 SSE 数据流（Content-Type: text/event-stream）
400请求参数错误请求体不是合法 JSON、缺少 model 字段或参数非法。检查请求体后重试
401密钥被拒（仅指定密钥模式）本站默认开放模式（任意密钥可用）；若部署者启用 AUTH_MODE=key，密钥需在 GATEWAY_KEYS 列表内。401 响应附官网与 QQ 频道/群引导字段
404接口或模型不存在请求了不存在的端点，或模型 ID 拼写错误 / 不在模型列表中
429限流 / 额度耗尽Workers AI 日额度用尽、上游限流、或官方自营通道排队超时。稍后重试即可
500服务器内部错误网关内部异常。可稍后重试；若持续出现请到交流群反馈
502上游不可达上游网关超时 / 密钥池不可用 / 上游返回 5xx。稍后重试
503服务暂不可用Nvidia 密钥池全部繁忙（all keys busy）。稍后重试

模型状态字段（/v1/models 返回）

status含义处理建议
（无）正常可用直接调用
exhaustedWorkers AI 今日免费额度已用尽等待每天 00:00 UTC 自动重置，或切换其他平台模型
unavailable模型在上游被封锁（3+ 密钥无访问权限）约 10 分钟后自动恢复，期间可先切换其他模型

健康评分（health.score）

每个模型附带近 100 次调用的健康评分（0-100，由成功率 / 延迟 / 稳定性加权计算）。90+ 优秀、70-89 良好、50-69 一般、<50 较差，可作为选择稳定模型的参考。
